## 1. Архитектура — что нужно знать перед тестированием

### Файлы

| Файл | Роль |
|------|------|
| `tg-app/index.html` | Единственная HTML-страница; все 8 экранов — `<div class="screen">` |
| `tg-app/js/data.js` | Данные мастера (`MASTER`), 7 услуг (`SERVICES`), генерация дат и слотов |
| `tg-app/js/tg.js` | Обёртка Telegram WebApp SDK; в браузере — заглушка |
| `tg-app/js/router.js` | SPA-роутер: стек истории, анимации переходов |
| `tg-app/js/app.js` | Вся логика экранов, обработчики событий |
| `tg-app/css/style.css` | Дизайн-система: переменные, компоненты, анимации |

### Хранилище данных

| Ключ | Хранилище | Что хранит |
|------|-----------|------------|
| `beauty_onboarding_shown` | `localStorage` | Флаг: онбординг уже показан (`'1'` или отсутствует) |
| `beauty_offer_shown_v2` | `localStorage` | Флаг: оффер-модалка уже была показана |
| `beauty_appointments` | `localStorage` | JSON-массив записей клиента |
| `tg_booking_draft` | `sessionStorage` | Черновик флоу записи (fallback если нет CloudStorage) |

### Режимы работы

**Браузер** — кнопки MainButton и BackButton Telegram скрыты; вместо них видны кнопки с классом `browser-only`. Данные пользователя: имя `Гость`, username `Открыто в браузере`.

**Telegram** — кнопки `browser-only` скрыты; работают нативные `MainButton` (зелёная кнопка снизу) и `BackButton` (стрелка в шапке Telegram). Имя и username берутся из `initDataUnsafe.user`.

## 2. Как запустить локально

### Требования

- Любой HTTP-сервер (браузер блокирует `file://` для localStorage в некоторых версиях Safari)
- Node.js не нужен; бэкенда нет

### Вариант 1 — Python (встроен в macOS/Linux)

```bash
cd tg-app
python3 -m http.server 8080
# Открыть: http://localhost:8080
```

### Вариант 2 — VS Code Live Server

Установить расширение «Live Server», ПКМ на `tg-app/index.html` → «Open with Live Server».

### Вариант 3 — npx serve

```bash
npx serve tg-app
```

### Вариант 4 — открыть файл напрямую

`tg-app/index.html` двойным кликом в Проводнике/Finder.  
Работает для большинства проверок, кроме кейсов с `localStorage` в Safari.

## 3. Как тестировать в Telegram

1. Убедиться, что Telegram-бот `@beauty_lusia_bot` настроен с Menu Button → URL продакшн-деплоя (уточни у владельца проекта)
2. Открыть бота в Telegram на iOS или Android
3. Нажать кнопку меню (или `/start`) → Mini App откроется поверх чата
4. Для новой сессии очистить данные: в браузере DevTools → Application → Local Storage

> **Важно:** HTTPS обязателен для Telegram Mini App. Продакшн на Vercel уже настроен. Для локального тестирования в Telegram используй ngrok или аналог.

## 4. Сброс состояния перед тестом

Перед каждым независимым тест-кейсом выполни в DevTools → Console:

```js
// Полный сброс (онбординг + оффер + все записи)
localStorage.clear();
sessionStorage.clear();
location.reload();

// Только сбросить онбординг (показать его снова)
localStorage.removeItem('beauty_onboarding_shown');
location.reload();

// Только сбросить оффер-модалку
localStorage.removeItem('beauty_offer_shown_v2');
location.reload();

// Посмотреть текущие записи
JSON.parse(localStorage.getItem('beauty_appointments') || '[]');

// Добавить тестовую запись вручную (для проверки экрана «Мои записи»)
const apt = {
  id: 'apt-test-001',
  serviceId: 'gel-manicure',
  serviceName: 'Маникюр с гель-лаком',
  serviceEmoji: '💅',
  date: new Date(Date.now() + 86400000 * 3).toISOString().slice(0, 10), // +3 дня
  time: '14:00',
  price: 'от 2 500 ₽',
  status: 'upcoming'
};
const list = JSON.parse(localStorage.getItem('beauty_appointments') || '[]');
list.unshift(apt);
localStorage.setItem('beauty_appointments', JSON.stringify(list));
location.reload();
```

## 5. Экраны и тест-кейсы

### Экран 0 — Онбординг

**Когда показывается:** только при первом открытии, если в `localStorage` отсутствует ключ `beauty_onboarding_shown`.

**Элементы:**
- Приветственный текст `Привет! 👋` (в Telegram — `Привет, [Имя]! 👋`)
- 3 пункта фич: Посмотреть услуги, Записаться онлайн, Получать напоминания
- Кнопка `Начать` (id `onboarding-start`)

| # | Шаги | Ожидаемый результат |
|---|------|---------------------|
| O-1 | Открыть приложение первый раз (нет `beauty_onboarding_shown`) | Виден экран онбординга, не главная |
| O-2 | Нажать кнопку «Начать» | Анимация: онбординг уходит влево, появляется главная. В `localStorage` появляется `beauty_onboarding_shown = '1'` |

| O-5 | Открыть в Telegram с аккаунтом у которого есть `first_name` | Приветствие: `Привет, [Имя]! 👋` вместо `Привет! 👋` |

### Оффер-модалка

**Когда показывается:** один раз при первом входе на главную. Управляется ключом `beauty_offer_shown_v2`.

**Элементы:**
- Заголовок: «Скидка 15% на первую запись»

- Кнопка «Пропустить»

| # | Шаги | Ожидаемый результат |
|---|------|---------------------|
| M-1 | Первый вход (нет `beauty_offer_shown_v2`) | Модалка появляется через ~1 с после главной |

| M-5 | При повторных входах (уже был онбординг) | Модалка появляется при каждом холодном старте пока не показана — т.е. один раз |

| Ca-3 | Нажать «Оставить запись» | Возврат к экрану «Мои записи», запись не изменена |
| Ca-4 | Нажать «←» в шапке | То же что «Оставить запись» |
| Ca-5 | В Telegram: BackButton | Возврат к «Мои записи» без отмены |

## 6. Навигация — полная схема переходов

```
[Онбординг] → (кнопка «Начать») → [Главная]

          ┌─────────────────────────────┤
          │                             │
     (тап на фото)           (тап «Записаться» на карточке)
          │                             │
          ▼                             │
   [Карточка услуги] ──────────────────►│
          │                             │

                                 [Бронирование]
                                        │
                                        ▼
                                 [Подтверждение]
                                        │
                                        ▼
                                    [Успех]
                                   │       │

                              [Мои записи] [Главная]
                                   │
```

### BackButton — что делает на каждом экране

| Экран | BackButton |
|-------|-----------|
| Главная | Скрыт (закрывает приложение нативно) |
| Карточка услуги | → Главная |
| Бронирование | → Карточка услуги (если пришли через неё) или → Главная (если пришли напрямую с главной) |
| Подтверждение | → Бронирование |
| Успех | → Главная |
| Мои записи | Скрыт |
| Подтв. отмены | → Мои записи |

## 7. Сквозные тест-кейсы (happy path)

### Флоу 1 — Первый пользователь, полная запись

1. Открыть приложение (нет данных в localStorage)
2. Появляется онбординг → нажать «Начать»
3. Появляется оффер → нажать «Пропустить»
4. Нажать «Записаться» на карточке «Маникюр с гель-лаком»
5. Выбрать ближайший будний день, слот 12:00
6. Нажать «Далее →»
7. Проверить данные на экране подтверждения
8. Нажать «Подтвердить запись»
9. Дождаться (~900 мс) экрана успеха с анимацией чекмарка
10. Нажать «К моим записям» — запись видна в «Предстоящие»

**Ожидаемый результат:** запись сохранена, в localStorage появилась запись с `status: 'upcoming'`.

---

### Флоу 2 — Повторный пользователь, отмена записи

1. Создать запись (Флоу 1)
2. Перейти в «Мои записи»
3. Нажать «Отменить» на карточке
4. На экране подтверждения нажать «Да, отменить»
5. Проверить: запись переехала в «История» со статусом «Отменена»
6. Нажать «Записаться снова» → появляется экран бронирования с «Маникюр с гель-лаком»

---

### Флоу 3 — Навигация через категорию, прямая запись

1. На главной нажать чип «Комбо»
2. Появилась 1 карточка «Маникюр + Педикюр»
3. Нажать «Записаться» на карточке
4. На экране бронирования в подсказке: «Маникюр + Педикюр», «от 5 000 ₽»
5. Выбрать дату и слот → «Далее →»
6. Подтвердить → Успех

## 10. Тестирование в разных средах

| Среда | Что особенного |
|-------|----------------|
| Chrome Desktop | Полное тестирование логики и UI. MainButton/BackButton не работают (заглушка) |
| iOS Safari | Проверить: нет зависания при загрузке. Шрифт SF Pro. Safe area внизу не перекрывает кнопки |
| Telegram iOS | MainButton, BackButton, HapticFeedback (вибрация), `openTelegramLink`. Тема берётся из Telegram |
| Telegram Android | То же что iOS. BackButton — физическая кнопка «Назад» на Android |
| Telegram Desktop | MainButton и BackButton работают в отдельном окне Mini App |

## 11. Что НЕ тестировать (намеренные ограничения MVP)

- **Бэкенд / реальные записи** — в MVP данные хранятся только в `localStorage`, сервера нет
- **Верификация initData** — HMAC-верификация не реализована в MVP (запланирована в v2)
- **Push-уведомления** — бот `beauty_lusia_bot` может не быть настроен на напоминания
- **Онлайн-оплата** — отсутствует в MVP
- **Выбор мастера** — только один мастер (Люся)
- **Кнопка «Перенести»** — открывает новый флоу бронирования, старое время не сохраняется

## 12. Как сообщать о баге

При создании баг-репорта указывай:

1. **Среда:** браузер (Chrome/Safari/Firefox) ИЛИ Telegram (iOS/Android/Desktop)
2. **Предусловие:** что было в `localStorage` (вывод `JSON.stringify(localStorage)` из консоли)
3. **Шаги воспроизведения** (нумерованный список)
4. **Ожидаемый результат**
5. **Фактический результат**
6. **Скриншот или запись экрана** (обязательно для визуальных багов)
7. **Ошибки в консоли** (DevTools → Console)
