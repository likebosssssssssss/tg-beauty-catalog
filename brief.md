# Brief: Telegram Mini App — каталог услуг бьюти-мастера

> Версия: MVP 1.0  
> Дата: 2026-05-19  
> Целевая платформа: Telegram Mini App (iOS + Android)

---

## Концепция одной фразой

**Клиент видит красивую работу → хочет такую же → записывается за 60 секунд — не выходя из Telegram.**

---

## Список экранов MVP

| # | Экран | Назначение |
|---|-------|-----------|
| 1 | Главная — профиль + услуги | Витрина мастера, точка входа |
| 2 | Каталог услуг | Все услуги с фото, фильтр по категориям |
| 3 | Карточка услуги | Фото работ, цена, длительность |
| 4 | Выбор даты и времени | Горизонтальная полоса дат + слоты |
| 5 | Итог и подтверждение | Финальный чек перед записью |
| 6 | Успех | Запись оформлена |
| 7 | Мои записи | Предстоящие визиты + история |

- `expand()` при запуске — полноэкранный режим
- `themeParams` — все цвета из темы Telegram
- `initData` — авто-получение имени пользователя

- `BackButton` — перехватить, вернуть на Экран 3
- `MainButton` заблокирован до выбора слота
- `enableClosingConfirmation()` — включить
- `HapticFeedback.impact('light')` при выборе слота
- `CloudStorage.set('draft', {...})` при каждом выборе
- Авто-выделить ближайшую доступную дату при открытии

## Технические требования

### Инициализация

```
При старте:
1. Telegram.WebApp.expand()
2. Читаем themeParams → задаём CSS-переменные
3. Проверяем initData → получаем user.id, first_name, username
4. BackButton.onClick → внутренний роутер
```

### Состояния загрузки

- Все экраны с данными: **skeleton loaders** (не спиннер)
- Цель: первый контент < 1.5 сек
- Lazy-load для фото (intersection observer)

### Хранилище

| Данные | Где хранить |
|--------|-------------|
| Черновик записи (услуга, дата, слот) | `CloudStorage` |
| Записи клиента (история) | Backend (PostgreSQL) |
| Информация о мастере, услуги | Backend |
| UI-тема | `themeParams` (не хранить) |

### Безопасность

- `initData` верифицировать через HMAC-SHA256 на сервере **обязательно**
- Не принимать `user_id` из тела запроса — только из верифицированного `initData`

## Чего НЕ будет в версии 1.0

### Исключено осознанно

| Функция | Причина исключения |
|---------|------------------|
| Онлайн-оплата / депозит | Сложная интеграция, требует Telegram Payments + тест на iOS/Android |
| Отзывы клиентов | Нужна модерация; добавить в v2 |
| Портфолио / отдельная галерея | Фото есть на карточках услуг; отдельный экран — v2 |
| «О мастере» отдельный экран | Информация в шапке Главной — достаточно для MVP |
| Акции и скидки | Механика промокодов — v2 |
| Выбор мастера | MVP рассчитан на одного мастера; multi-master — v2 |
| Push-напоминания | Бот нужен для этого; реализовать параллельно, не блокирует UI |
| Выбор дизайна / загрузка рефа | Ценная функция, но усложняет флоу; v2 |
| Программа лояльности | v3 |
| Аналитика для мастера | v2 |
| Кнопка «Поделиться» | Добавить на Экран 6 в v1.5 — быстро, но не критично |

### Что упрощено в v1

| Что упрощено | Как в v1 | Как в v2 |
|-------------|---------|---------|
| Отмена записи | Экран подтверждения без выбора причины | Причина + условия депозита |
| Перенос | Открывает флоу с начала (экран дат) | Умный выбор: «перенести эту же услугу» |
| Пустые состояния | Текст + кнопка | Иллюстрация |
| Skeleton loaders | Базовые серые заглушки | Анимированные shimmer |

## Метрики успеха MVP

| Метрика | Цель |
|---------|------|
